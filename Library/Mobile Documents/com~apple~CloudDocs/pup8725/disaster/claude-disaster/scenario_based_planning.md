# Scenario-Based Emergency Planning
## Top 10 Risk Scenarios for Urban Family

### Scenario Planning Methodology
Each scenario includes:
- **Trigger Events**: What starts the scenario
- **Timeline**: How events unfold
- **Decision Points**: Critical choices to make
- **Resource Requirements**: What you'll need
- **Recovery Strategy**: How to return to normal

---

## SCENARIO 1: Extended Power Outage (Winter)
**Probability**: 53% annually | **Duration**: 12-48 hours | **Impact**: Medium

### Timeline
**Hour 0-2**: Power goes out during winter storm
- Check if outage is local or widespread
- Activate emergency lighting
- Check on neighbors, especially elderly

**Hour 2-6**: Assess situation
- Monitor radio for utility updates
- Begin conserving phone battery
- Start using non-electric food preparation

**Hour 6-24**: Adaptation phase
- Implement heating strategy (safe indoor heating only)
- Manage food safety (refrigerator stays cold ~4 hours)
- Maintain child's routine with games/activities

**Hour 24+**: Extended response
- Consider relocation to warming center
- Coordinate with extended family/friends
- Manage work/school obligations

### Decision Tree
```
Power Out → Check scope → Local? → Wait 2-4 hours → Still out? → Activate backup plan
                      → Widespread? → Immediate backup plan → Duration estimate → Stay/Go decision
```

### Resource Checklist
- [ ] Battery-powered radio
- [ ] LED flashlights (avoid candles with child)
- [ ] Portable phone chargers
- [ ] Non-perishable food for 3 days
- [ ] Manual can opener
- [ ] Warm clothing and blankets
- [ ] Board games/books for child entertainment
- [ ] Cash for emergency purchases

### Recovery Actions
- [ ] Check all appliances before power restoration
- [ ] Assess food safety (when in doubt, throw out)
- [ ] Recharge all devices
- [ ] Restock emergency supplies used
- [ ] Document any damage for insurance

## SCENARIO 2: Child Medical Emergency
**Probability**: 48% annually | **Duration**: 4-24 hours | **Impact**: High stress

### Timeline
**Minute 0-5**: Injury/illness occurs
- Assess severity using ABC (Airway, Breathing, Circulation)
- Apply first aid if trained and appropriate
- Decide: treat at home, urgent care, or ER

**Minute 5-30**: Response phase
- Call pediatrician or 911 based on severity
- Gather medical information and insurance cards
- Arrange transportation
- Notify other parent/emergency contacts

**Hour 1-6**: Medical care phase
- Provide medical history to healthcare providers
- Make childcare arrangements if needed
- Coordinate with work/school notifications
- Manage other parent's travel if away

**Hour 6-24**: Stabilization
- Follow medical instructions
- Arrange follow-up care
- Manage household needs
- Process insurance claims

### Decision Matrix
| Symptoms | Action | Timeline |
|----------|--------|----------|
| Unconscious, severe bleeding, difficulty breathing | Call 911 immediately | 0-2 minutes |
| High fever, persistent vomiting, severe pain | Call pediatrician, consider ER | 5-15 minutes |
| Minor cuts, bruises, mild illness | First aid, monitor, call if worsens | 30+ minutes |

### Resource Checklist
- [ ] Pediatric first aid certification
- [ ] Complete first aid kit
- [ ] Medical information cards
- [ ] Insurance cards and ID
- [ ] Emergency contact list
- [ ] Comfort items for child
- [ ] Snacks and entertainment for waiting
- [ ] Phone chargers

### Communication Plan
1. **Immediate**: Call other parent
2. **Within 30 minutes**: Notify childcare/school
3. **Within 1 hour**: Update extended family
4. **Ongoing**: Regular updates to key contacts

## SCENARIO 3: Job Loss (Primary Earner)
**Probability**: 15% annually | **Duration**: 30-180 days | **Impact**: High financial

### Timeline
**Day 0**: Job loss occurs
- File for unemployment benefits immediately
- Review severance package and benefits continuation
- Assess immediate financial situation
- Notify spouse and begin family discussion

**Week 1**: Immediate response
- Apply for COBRA health insurance if needed
- Review and reduce non-essential expenses
- Begin networking and job search activities
- Consider temporary/contract work options

**Month 1**: Adaptation phase
- Establish new daily routine
- Intensify job search efforts
- Consider retraining or skill development
- Evaluate childcare needs changes

**Month 2-6**: Extended response
- Consider relocation if necessary
- Explore career pivots or entrepreneurship
- Manage stress and family dynamics
- Prepare for potential long-term changes

### Financial Triage Plan
**Immediate (Week 1)**:
- [ ] Stop all non-essential spending
- [ ] Contact creditors to discuss payment plans
- [ ] Apply for unemployment benefits
- [ ] Review emergency fund status

**Short-term (Month 1)**:
- [ ] Reduce housing costs if possible
- [ ] Cancel subscriptions and memberships
- [ ] Consider temporary income sources
- [ ] Apply for assistance programs if needed

**Medium-term (Month 2+)**:
- [ ] Consider downsizing housing
- [ ] Evaluate career change options
- [ ] Use professional development resources
- [ ] Maintain health insurance coverage

### Resource Requirements
- [ ] 6-month emergency fund (ideal)
- [ ] Updated resume and LinkedIn profile
- [ ] Professional network contacts
- [ ] Unemployment benefits information
- [ ] Health insurance alternatives research
- [ ] Childcare flexibility options

## SCENARIO 4: Severe Weather Event (Hurricane/Blizzard)
**Probability**: 20% annually | **Duration**: 24-72 hours | **Impact**: Medium-High

### Pre-Event (24-48 hours warning)
- [ ] Monitor weather forecasts closely
- [ ] Secure outdoor furniture and objects
- [ ] Fill bathtubs and containers with water
- [ ] Charge all electronic devices
- [ ] Prepare vehicle (fuel, emergency kit)
- [ ] Coordinate with neighbors and family

### During Event (0-24 hours)
- [ ] Stay indoors and away from windows
- [ ] Monitor emergency broadcasts
- [ ] Avoid using candles (fire risk)
- [ ] Check on neighbors when safe
- [ ] Document any damage with photos
- [ ] Conserve phone battery for emergencies

### Post-Event (24-72 hours)
- [ ] Assess home and property damage
- [ ] Check utilities before use
- [ ] Clear debris safely
- [ ] Contact insurance company
- [ ] Help neighbors if possible
- [ ] Begin cleanup and repairs

### Evacuation Decision Tree
```
Evacuation Order → Mandatory? → Leave immediately
                            → Voluntary? → Assess personal risk → High risk? → Leave
                                                              → Manageable? → Shelter in place with full prep
```

## SCENARIO 6: Home Uninhabitable (Fire/Flood)
**Probability**: 2.64% annually | **Duration**: 30-365 days | **Impact**: Very High

### Immediate (0-24 hours)
- [ ] Ensure family safety first
- [ ] Contact emergency services if needed
- [ ] Document damage with photos/video
- [ ] Contact insurance company immediately
- [ ] Secure temporary shelter

### Short-term (1-7 days)
- [ ] Find temporary housing (hotel, family, friends)
- [ ] Retrieve essential items if safe to do so
- [ ] Notify work, school, and service providers
- [ ] Begin insurance claim process
- [ ] Arrange for pet care if needed

### Medium-term (1-6 months)
- [ ] Secure longer-term temporary housing
- [ ] Coordinate repairs and reconstruction
- [ ] Manage insurance claim process
- [ ] Maintain child's school and routine stability
- [ ] Address emotional trauma and stress

### Essential Documents Kit (Fireproof Safe)
- [ ] Insurance policies
- [ ] Birth certificates
- [ ] Social Security cards
- [ ] Passports
- [ ] Financial account information
- [ ] Medical records
- [ ] Property deeds/lease agreements
- [ ] Recent photos of family and property

## SCENARIO 9: Childcare Provider Emergency
**Probability**: 48% annually | **Duration**: 1-7 days | **Impact**: High disruption

### Immediate Options (Same Day)
1. **Parent flexibility**: Work from home or take leave
2. **Family support**: Grandparents, siblings
3. **Neighbor network**: Trusted neighbors with children
4. **Emergency services**: Drop-in childcare centers

### Short-term Solutions (2-7 days)
1. **Backup provider**: Pre-arranged secondary childcare
2. **Parent coordination**: Alternating work schedules
3. **Community resources**: Parent co-ops, church groups
4. **Professional services**: Temporary nanny services

### Prevention Strategies
- [ ] Maintain relationships with 2-3 backup providers
- [ ] Join parent networks for mutual support
- [ ] Negotiate work flexibility in advance
- [ ] Research drop-in childcare options

## SCENARIO 10: Identity Theft/Financial Fraud
**Probability**: 6.6% annually | **Duration**: 30-180 days | **Impact**: Medium-High

### Immediate Response (0-24 hours)
- [ ] Contact banks and credit card companies
- [ ] Place fraud alerts on credit reports
- [ ] File police report
- [ ] Document all fraudulent activity
- [ ] Change all online passwords

### Short-term Actions (1-7 days)
- [ ] Contact credit bureaus for credit freeze
- [ ] File FTC identity theft report
- [ ] Review all financial statements
- [ ] Notify employers and government agencies
- [ ] Consider identity monitoring services

### Recovery Process (1-6 months)
- [ ] Work with financial institutions on claims
- [ ] Monitor credit reports regularly
- [ ] Rebuild damaged credit if necessary
- [ ] Implement stronger security measures
- [ ] Consider legal action if appropriate

### Prevention Measures
- [ ] Regular credit report monitoring
- [ ] Secure document storage and disposal
- [ ] Strong, unique passwords for all accounts
- [ ] Limited sharing of personal information
- [ ] Regular review of financial statements

## Cross-Scenario Resource Planning

### Universal Emergency Kit
Items needed across multiple scenarios:
- [ ] Battery-powered radio
- [ ] Flashlights and batteries
- [ ] First aid kit
- [ ] Emergency contact list
- [ ] Cash in small bills
- [ ] Important documents (copies)
- [ ] Medications (7-day supply)
- [ ] Non-perishable food and water

### Communication Plan Template
For any emergency scenario:
1. **Immediate family notification**
2. **Extended family updates**
3. **Work/school notifications**
4. **Neighbor/community check-ins**
5. **Service provider contacts**

### Financial Emergency Protocol
Standard steps for any financial impact:
1. **Assess immediate cash needs**
2. **Access emergency funds**
3. **Contact creditors if needed**
4. **Review insurance coverage**
5. **Document all expenses**
6. **Plan for recovery phase**

This scenario-based approach helps you practice decision-making and resource allocation for the most likely and impactful events your family might face.
