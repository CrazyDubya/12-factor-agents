# 📋 Manual Operations Guide - When Digital Systems Fail

## 🎯 Overview
When cyber attacks cripple digital infrastructure, knowing how to operate manually can mean the difference between paralysis and productivity. This guide covers non-digital alternatives for critical systems.

## 💰 Banking & Financial Operations

### **Without Online Banking**

#### **Manual Banking System**
1. **Checkbook Management**
   - Balance after EVERY transaction
   - Carbon copy checks for records
   - Register: Date | Check# | Payee | Amount | Balance
   - Monthly reconciliation with statements

2. **Cash Management**
   ```
   Weekly Cash Envelope System:
   - Groceries:     $___
   - Gas:          $___
   - Utilities:    $___
   - Emergency:    $___
   - Savings:      $___
   ```

3. **Payment Tracking**
   - Receipt folder system
   - Daily expense log
   - Handwritten ledger
   - Calculator verification

#### **Alternative Payment Methods**
- **Money Orders** - Post office, grocery stores
- **Cashier's Checks** - Bank issued, guaranteed
- **Traveler's Checks** - Pre-paid, replaceable
- **Barter System** - Goods/services exchange
- **IOU System** - Community trust network

### **Manual Bookkeeping**
```
Simple Ledger Format:

1/1  | Starting    | 1000   |         | 1000

```
Primary Frequency: 146.520 MHz (2m calling)

Check-in Times: 9:00 AM & 6:00 PM
Emergency Signal: 3 long, 3 short, 3 long

## 🗺️ Navigation Without GPS

### **Map and Compass Basics**

#### **Essential Tools**
- [ ] Local street maps
- [ ] Topographic maps
- [ ] Magnetic compass
- [ ] Protractor
- [ ] Ruler/Scale
- [ ] Pencil (not pen)

#### **Basic Navigation**
1. **Orient Map to North**
   - Align compass with map north
   - Identify landmarks
   - Triangulate position

2. **Route Planning**
   ```
   Checkpoint System:
   Start → Landmark 1 → Turn → Landmark 2 → Destination
   Time: ___  Distance: ___  Alternate: ___
   ```

3. **Dead Reckoning**
   - Pace counting (steps per 100m)
   - Time estimation
   - Bearing following
   - Back bearings

### **Celestial Navigation (Emergency)**
- **North Star** - End of Big Dipper points to Polaris
- **Sun Position** - Rises East, Sets West
- **Watch Method** - Point hour hand at sun, South is halfway to 12
- **Shadow Stick** - Track shadow movement for direction

## 🏠 Home Operations Manual Mode

### **Climate Control Without HVAC**

#### **Heating**
- **Passive Solar** - Open south curtains day, close night
- **Zone Heating** - Close unused rooms
- **Thermal Mass** - Water jugs absorb/release heat
- **Insulation** - Blankets on windows, doors
- **Body Heat** - Family gathering space

#### **Cooling**
- **Cross Ventilation** - Opposite windows open
- **Thermal Chimney** - Hot air rises, exits high
- **Evaporative** - Wet towels on windows
- **Shade Creation** - External covers, awnings
- **Night Flush** - Cool air overnight

### **Water Without Pumps**
1. **Gravity Systems**
   - Elevated storage
   - Siphon principles
   - Ram pumps

2. **Manual Pumps**
   - Hand pump well
   - Pitcher pump
   - Hydraulic ram

3. **Collection Methods**
   - Rain gutters → barrels
   - Dew collection
   - Condensation capture
