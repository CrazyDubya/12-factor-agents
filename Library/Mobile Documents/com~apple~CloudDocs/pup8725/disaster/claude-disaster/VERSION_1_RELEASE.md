## 🎯 Installation & Quick Start

### **System Requirements**
- Python 3.7+ (built-in on macOS)
- 10MB storage space
- No internet required for operation

### **Installation**
```bash
# Clone or download the system
cd disaster/

# Test the system
python3 system_test.py

# Launch main interface
python3 run_system.py
```

### **First Run**
```bash
# Safe launcher with error handling
python3 run_system.py

# Or run directly
python3 integrated_preparedness_system.py
```

## 🔍 Known Limitations (V1.0)

### **Identified Gaps (Addressed in V2.0)**
1. **Modern Threat Coverage**: Cyber attacks, EMP events, economic collapse
2. **Long-term Sustainability**: Extended scenarios beyond 72 hours
3. **Alert System Scope**: Limited to weather-related events
4. **Advanced Drill Scenarios**: Modern threat training simulations

### **Technical Constraints**
- Terminal-based interface (GUI planned for V2.0)
- SQLite databases (upgrade to PostgreSQL in V2.0)
- Single-user operation (multi-user support in V2.0)
