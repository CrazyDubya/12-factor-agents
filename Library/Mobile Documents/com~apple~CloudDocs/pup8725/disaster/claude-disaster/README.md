## 🛠️ Troubleshooting

### Common Issues

**Import Errors:**
```bash
python3 system_test.py  # Run diagnostics
```

**Permission Errors:**
```bash
chmod +x *.py  # Make scripts executable  
```

**Database Issues:**
```bash
rm -rf preparedness_data/  # Reset databases (will lose data)
```

### Getting Help

1. **Run Tests**: `python3 system_test.py`
2. **Check Files**: All `.py` files should be present
3. **Verify Permissions**: Ensure write access to directory
4. **Reset Data**: Delete `preparedness_data/` folder to start fresh
