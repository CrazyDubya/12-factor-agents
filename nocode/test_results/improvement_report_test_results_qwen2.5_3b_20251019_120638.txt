FEW-SHOT LEARNING RECOMMENDATIONS
================================================================================

**What is Few-Shot Learning?**
Providing example question-answer pairs before the actual task,
helping the model understand the expected format and approach.

**A/B Test: Few-Shot vs Zero-Shot**

**Branch A (Zero-Shot): Direct Question**
  Example: 'Explain REST API to a non-technical person'

**Branch B (Few-Shot): With Examples**
  Example:
  'Here are examples of technical concepts explained simply:
   Q: Explain a database to a non-technical person.
   A: A database is like a digital filing cabinet that stores
      and organizes information so you can find it quickly.

   Q: Explain cloud computing to a non-technical person.
   A: Cloud computing is like renting storage space and computers
      on the internet instead of buying your own.

   Now you try:
   Q: Explain REST API to a non-technical person.'

**When Few-Shot Helps Most:**
  - Complex formatting requirements
  - Specific tone/style needed
  - Unfamiliar task types
  - Consistency across multiple similar queries

TEMPERATURE TUNING RECOMMENDATIONS
================================================================================

**What is Temperature?**
Controls randomness in model outputs:
  - Low (0.0-0.3): Deterministic, focused, consistent
  - Medium (0.4-0.7): Balanced creativity and coherence
  - High (0.8-1.0): Creative, diverse, exploratory

**A/B Test: Temperature Variants**

**Branch A: Low Temperature (0.2)**
  Best for:
    - Factual questions
    - Logical reasoning
    - Math problems
    - Tasks requiring consistency
  Example: 'What is 2+2?' should always return 4

**Branch B: Medium Temperature (0.7)**
  Best for:
    - Creative writing
    - Brainstorming
    - Open-ended questions
    - Varied perspectives
  Example: 'Write a product tagline' benefits from variety

**Branch C: High Temperature (1.0)**
  Best for:
    - Creative fiction
    - Ideation sessions
    - Exploring alternatives
  Risk: May produce less coherent outputs

**Recommended Test Matrix:**
  Reasoning tasks → Test 0.1, 0.3, 0.5
  Content creation → Test 0.5, 0.7, 0.9
  Communication → Test 0.3, 0.5, 0.7
